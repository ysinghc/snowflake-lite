Generator

Mints IDs for one machine. The zero value is not usable; construct it with New, MustNew or NewFromEnv. All methods are safe for concurrent use.

New(machineID int64) (*Generator, error)

Returns a generator for machineID. Returns an error if the value is outside 0..1023.

MustNew(machineID int64) *Generator

Like New but panics on an invalid ID. Intended for program start-up with a constant.

NewFromEnv() (*Generator, error)

Reads the MACHINE_ID environment variable. If it is unset, the machine ID is the FNV-1a hash of the hostname modulo 1024. A malformed or out-of-range MACHINE_ID returns an error. See choose machine IDs for the collision risk of the fallback.

(*Generator) Next() ID

Returns the next unique, strictly ascending ID. It never blocks and never fails.

(*Generator) NextN(n int) []ID

Returns n IDs by calling Next in a loop. The slice is allocated once. IDs are ascending, but if other goroutines share the generator they may be interleaved with yours.

(*Generator) MachineID() int64

Reports the machine ID embedded in every ID this generator mints.

Decode and Parts

Decode(id ID) Parts

Splits an ID into its fields. It does not validate: any integer decodes to something.

type Parts struct {
	ID               ID        `json:"-"`
	Timestamp        time.Time `json:"timestamp"`
	MillisSinceEpoch uint64    `json:"millisSinceEpoch"`
	MachineID        uint64    `json:"machineID"`
	Sequence         uint64    `json:"sequence"`
}

Examples

A shared generator

var gen = snowflake.MustNew(mustEnvInt("MACHINE_ID"))

func newOrderID() string { return gen.Next().String() }

Check ordering

a, b := gen.Next(), gen.Next()
fmt.Println(b > a)                     // true
fmt.Println(a.Decode().MachineID)       // the generator's machine ID

Mint a batch

for _, id := range gen.NextN(1000) {
	insert(id.Int64())
}
