Run it

snowflake serve --machine 7 --addr :8080

It prints snowflake-lite serving on :8080 (machine 7). Every response carries Access-Control-Allow-Origin: *, so a static page can call it.

Endpoints

RequestResponse
GET /id{"id":"374208188427300864"}
GET /id?n=100{"ids":["…","…"]}. n is clamped to 1..10000; a non-numeric value means 1
GET /decode?id=…Fields of the ID. 400 with {"error":"invalid or missing id"} if it is not an integer
GET /healthz{"status":"ok"}
GET /Plain-text list of the endpoints

Any other path returns 404. IDs are always JSON strings.

When to use it

Use serve for local experiments, sidecars on a trusted network, or demos. For API keys, rate limits, other ID formats and metrics, use the platform server.
