Install

go install github.com/ysinghc/snowflake-lite/cmd/snowflake@latest

Or build from a checkout: go build -o snowflake ./cmd/snowflake.

Commands

CommandWhat it does
snowflake generate [N]Print N IDs, one per line. Default 1,000,000
snowflake bench [N]Measure throughput and check that IDs are strictly ascending
snowflake decode <ID>Split an ID into timestamp, machine and sequence, with a bit view
snowflake serveA tiny JSON server. See Simple HTTP server
snowflake serve-saasThe multi-format platform. See Platform API

Counts accept underscores for readability: snowflake generate 1_000_000.

Flags

FlagApplies toMeaning
--machine IDgenerate, bench, serve, serve-saasMachine ID 0..1023. For the first four the default is $MACHINE_ID, then a hostname hash. For serve-saas the default is 0, then the pod ordinal (see Deployment)
--addr ADDRserve, serve-saasListen address. Default :8080
--datacenter IDserve-saasDatacenter ID 0..31
--web DIRserve-saasDirectory of static dashboard files. Default web
Flag order

Put flags before the count: snowflake generate --machine 3 1000. Go's flag parser stops at the first positional argument.

Examples

Generate a million IDs

$ time ./snowflake generate 1000000 > /dev/null

Output goes through a 1 MiB buffered writer so the timing reflects generation, not system calls.

Benchmark

$ ./snowflake bench 5000000
generated : 5,000,000 IDs
elapsed   : …
rate      : … IDs/sec
sortable  : true  (strictly ascending ⇒ also collision-free)
machine   : 7
last ID   : …

A strictly ascending sequence cannot contain duplicates, so one check proves both ordering and uniqueness.

Decode

$ ./snowflake decode 374208188427300864
ID        : 374208188427300864
timestamp : 2024-…  (… ms since 2024-01-01)
machine   : 7
sequence  : 0
bits      : 0 <41 bits> <10 bits> <12 bits>

Invalid input exits with status 1 and prints error: … to standard error. Running with no command prints usage and exits with status 2.
