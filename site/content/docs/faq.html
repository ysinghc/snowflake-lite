Questions

Can two machines produce the same ID?

Only if they share a machine ID. Give every running generator a distinct value from 0 to 1023 and IDs cannot collide.

Are IDs sorted globally?

Within one generator, strictly. Across generators, IDs sort by timestamp first, so the order is only as accurate as the machines' clocks. Two machines whose clocks differ by 5 ms can interleave out of real-time order.

Why does Next() not return an error?

Because nothing can go wrong at call time. A backward clock is absorbed by the sequence, and a full millisecond is absorbed by advancing a logical clock.

What if I need more than 1,024 machines?

The layout is fixed. For more writers you would need a different bit split, which this package does not offer.

Can I change the epoch?

Not in the core package; Epoch is a constant. IDs from this package are only comparable with each other.

Is it safe to expose IDs publicly?

IDs reveal when they were created and which machine made them. They are identifiers, not secrets, and they are guessable. Do not use them as access tokens.

Why a string in JSON?

IDs exceed 253, the largest integer a JavaScript number holds exactly.

What this package does not do

  • It does not coordinate machine IDs. You assign them.
  • It does not persist generator state across restarts.
  • It does not generate IDs that are hard to guess.
  • It does not parse or validate IDs from other Snowflake implementations: the epoch and field widths are specific to this package.
