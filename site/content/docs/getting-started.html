Install

You need Go 1.23 or newer. The library uses only the standard library.

go get github.com/ysinghc/snowflake-lite@latest

The importable package is snowflake:

import "github.com/ysinghc/snowflake-lite/snowflake"

Generate IDs

package main

import (
	"fmt"

	"github.com/ysinghc/snowflake-lite/snowflake"
)

func main() {
	g := snowflake.MustNew(7) // machine ID, 0..1023

	id := g.Next()
	fmt.Println(id)        // 374208188427300864
	fmt.Println(id.Time()) // when it was minted, in UTC
}

A Generator is safe for concurrent use. Create one per process and share it. Do not create one per request: each generator keeps its own sequence state, and two generators with the same machine ID can produce the same ID.

Decode an ID

p := id.Decode() // or snowflake.Decode(id)
fmt.Println(p.Timestamp, p.MachineID, p.Sequence)

Parts holds the timestamp, the milliseconds since the epoch, the machine ID and the sequence number.

Choose machine IDs

Uniqueness across processes depends on one rule: no two running generators share a machine ID. There are 1,024 values to hand out.

SituationWhat to do
Single processsnowflake.MustNew(0)
Several services or podsSet MACHINE_ID per process and call snowflake.NewFromEnv()
KubernetesUse a StatefulSet and derive the ID from the pod ordinal (the number at the end of the pod name)
Local developmentNewFromEnv() with no variable hashes the hostname
Warning

The hostname fallback hashes to only 10 bits, so two hosts can land on the same value. Treat it as a development convenience and assign IDs explicitly in production.

Send IDs over JSON

IDs are larger than 253. A JSON number, or a JavaScript number, silently rounds the low bits. Always send IDs as strings:

json.Marshal(map[string]string{"id": id.String()})

Store IDs

IDs are positive int64 values, so they fit a SQL BIGINT (PostgreSQL bigint, MySQL BIGINT). Because they increase with time, they make good clustered primary keys: new rows append at the end of the index instead of landing at random positions.
