Command-line program

go install github.com/ysinghc/snowflake-lite/cmd/snowflake@latest

This installs the snowflake command into $(go env GOPATH)/bin. No prebuilt binaries or container images are published.

Verify what you download

The Go module system checks every download against a public, tamper-evident checksum database. After go get, run:

go mod verify

To pin an exact version, name the tag, for example @v0.1.1. Versions follow semantic versioning; while the major version is 0, minor releases may change the API.
