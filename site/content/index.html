Unique IDs that sort by time.

snowflake-lite is a small Go library that mints 64-bit, time-ordered, collision-free IDs with no coordination between machines. One atomic compare-and-swap per ID: no mutex, no sleeping, no error when the clock steps back.

Why this one

Lock-free

The whole generator state is one atomic word. Each ID costs a single CompareAndSwap.

Never fails

A backward clock step cannot break uniqueness or ordering. Next() has no error return.

Sortable

IDs from one generator are strictly ascending. They are positive int64 values that fit a SQL BIGINT.

    Use it

    import "github.com/ysinghc/snowflake-lite/snowflake"

g := snowflake.MustNew(7) // machine ID 0..1023
id := g.Next()            // strictly ascending, safe for concurrent use
fmt.Println(id, id.Time())
