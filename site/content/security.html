Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's private reporting:

Report a vulnerability

Include the affected version, a description of the problem, and steps or code to reproduce it. You will get an acknowledgement, and we will agree on a fix and disclosure timeline with you. Please give us reasonable time to release a fix before you publish details.

Supported versions

Only the latest release receives fixes. While the project is at version 0.x, upgrade to the newest tag to get them.

What IDs are not

Snowflake IDs are predictable by design: they encode a time, a machine and a counter. Guessing the next ID is not a vulnerability. Do not use them as secrets, session tokens or access control.
