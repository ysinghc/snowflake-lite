02 Anatomy of an ID

63 usable bits: a 41-bit millisecond timestamp, a 10-bit machine ID, and a 12-bit per-millisecond sequence. Paste any ID to inspect it, or generate one above.

03 Benchmark

Run the real generation loop inside the browser and measure throughput. A strictly-ascending result is, by definition, both sortable and collision-free.
